PEBA (polyether block amide)

A polyamide/polyether thermoplastic elastomer. This entry describes eSUN PEBA-90A; other grades can differ.

Open in interactive comparison

Values below describe the catalog’s representative grades, with sources on each row. Manufacturer datasheets and independent tests are labeled by source type and date. Printed orientation, test method, conditioning and formulation can change the result. Unknown values are —; a listed use is not a certification.

Nozzle temperature (°C)

230–260 °C; 240 °C recommended.

Bed temperature (°C)

60–90 °C

  • eSUN PEBA-90A Technical Data Sheet v1.0 (Aug 2025), checked 2026-10-17 · 2025-08 · tds

Drying

70–75 °C for 6–8 h; re-dry after receiving or extended exposure.

  • eSUN PEBA-90A Technical Data Sheet v1.0 (Aug 2025), checked 2026-10-17 · 2025-08 · tds

Volumetric flow (mm³/s)

9 mm³/s maximum in eSUN spiral-vase test; mechanical specimens used 2 mm³/s. Linear recommendation 25–110 mm/s is a separate quantity.
