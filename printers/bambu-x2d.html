Bambu Lab X2D

Dual-nozzle enclosed CoreXY machine with a 65 C heated chamber and a 120 C bed, positioned as the accessible dual-nozzle model below the H2 series.

Firmware and openness

The bambulab GitHub organisation carries 11 repositories (Bambu Studio, wxWidgets/boost/ffmpeg forks, the wiki); none is printer firmware.
