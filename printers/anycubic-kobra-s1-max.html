Problems & troubleshooting

Error 10106: local storage is full

The official response to insufficient local memory starts by deleting local files. Factory reset is a later option that also removes stored network, calibration and print-history information, so preserve what is needed before that step.

Applies to: Kobra S1 Max; use this procedure for code 10106 rather than treating every failed upload as a memory fault.
