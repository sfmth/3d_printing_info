Problems & troubleshooting

Klipper print-start failure: check the mesh configuration

In this conversion, PRINT_START fails when KAMP is disabled and no default mesh exists. Check that combination before changing hardware; when using KAMP instead, enable object labels in the slicer as the maintainer requires.

Applies to: SV06 Plus branch in bassamanator’s Klipper configuration; this is a conversion-specific macro condition, not a stock Marlin fault.

Firmware & software

SV06 Plus Klipper configuration

The dedicated Plus branch provides the printer configuration and macros for a Klipper conversion. Install Klipper on an external host, flash the matching controller firmware and follow the initial configuration checks before running print macros.

Applies to: Sovol SV06 Plus stock controller; use the sv06-plus branch, not the smaller SV06 configuration or an ACE image.
