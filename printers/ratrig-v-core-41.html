Problems & troubleshooting

First-layer or configuration trouble after a RatOS migration

The migration guide calls out changed pin assignments, duplicate configuration and older Beacon-related customizations. Compare the wiring and generated configuration with the current model’s defaults before restoring custom sections.

Applies to: RatOS 2.1 RC3-to-RC4 transition. Stock-wired V-Core 4.0/4.1 kits differ from custom board and accessory layouts.

Firmware & software

RatOS: configure the Klipper stack for the installed build

RatOS supplies the printer configuration and supporting Klipper workflow. Its setup wizard distinguishes V-Core 4.0 and 4.1 and generates supported hardware options, including IDEX. Back up custom configuration and follow the documented migration rather than carrying an old configuration forward wholesale.

Applies to: V-Core 4.0 / 4.1. The RC3-to-RC4 migration requires a fresh SD-card installation; custom board wiring needs explicit pin verification.
