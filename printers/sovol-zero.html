Problems & troubleshooting

Mainline startup error after updating: match MCU builds

On the documented mainline conversion, an unknown-command startup error after a host update can mean its MCU applications are out of step. The maintainer requires the host and both MCU applications to use the same Klipper commit.

Applies to: Sovol Zero mainline migration documented by lexfrei and verified on one printer; this is not a diagnosis for an unchanged Sovol firmware installation.

Firmware & software

Zero mainline Klipper migration

The maintainer documents replacing Sovol’s vendor fork and preserving numeric knob-screen codes through an optional plugin. The knowledge base includes controller pinouts and flashing procedures; its author reports verification on one printer.

Applies to: Sovol Zero; one-machine validation, so confirm board and toolhead revisions before following the migration.
