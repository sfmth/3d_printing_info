# Printed examples and photo credits

Creator-reported prints from the linked Printables listings, checked 2026-10-17. These are creator reports, not independent material tests or certification. Never infer an exact grade from a related polymer or a recommendation. Notes identify the relevant component when a photograph contains several materials.

The complete image URL, model URL, creator, listing license, license link, material evidence, dimensions and image SHA-256 are maintained in `data/print-examples.json`. Each material ID maps to a list of examples. Images are optional: model-only examples retain their creator evidence and direct links, without assigning an unverified photo. PVA is explicitly a sacrificial-support example; the finished model is a separate material.

Downloaded source-hosted image and thumbnail bytes are preserved without modification, including their metadata. CSS controls display size. Attribution and the specific listing license appear beside the photograph and in each example story. Some listings use noncommercial, share-alike or no-derivatives licenses; keep those terms with the individual asset. The PC/ABS GPL model is linked without reusing its image.
